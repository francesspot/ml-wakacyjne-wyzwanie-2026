> 🎓 AI/ML track of the **Summer Challenge 2026** (*Wakacyjne Wyzwanie*) run by the **KN Solvro** student research group (Wrocław University of Science and Technology)

Tasks ranging from data analysis to LLM agents. My solutions are on the [`francesspot-dev`](../../tree/francesspot-dev) branch, and the final project has its own repo — [Neuromorphic Vision](https://github.com/francesspot/ml-neuromorficzne-widzenie).

## 🪜 My tasks

| # | Topic | What I did |
|---|---|---|
| 1 | Data analysis | **EDA of the Titanic dataset** — missing data, visualisations, cleaning and feature preparation |
| 2 | ML basics | Predicting Titanic survival: a baseline, a **decision tree** and **KNN** tuned with grid search, with a leak-free data split — **~80% accuracy** (vs 61% for the baseline) |
| 3 | Computer vision | My own **U-Net** in **PyTorch** for semantic image segmentation (Pascal VOC) |
| 4 | NLP & agents | An **agentic RAG assistant** for recipes: PDFs embeddings Chroma vector store; a **LangGraph** agent (Gemini) with tools for finding recipes and scaling portions, plus automated evaluation (hit rate, MRR, LLM-as-a-judge) |

I ran the notebooks in Google Colab. The `main` branch holds the course materials.
